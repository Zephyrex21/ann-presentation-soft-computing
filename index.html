SEC 02 · FOUNDATIONS

It Starts With a Neuron

Your brain has about 86 billion tiny cells called neurons. They talk to each other using tiny electrical and chemical signals.

When you practise something, the connections between neurons get stronger — that is a key part of how the brain learns. Computers copy this idea using numbers called weights.
SEC 03 · FOUNDATIONS

Nature Inspired the Machine

A computer neuron is a simplified copy of a brain neuron — every part has a matching part.

1943 · McCULLOCH & PITTS — proposed the first mathematical model of a neuron: a simple on/off threshold unit

SEC 05 · ARCHITECTURE

One Neuron Is Not Enough

One neuron is too simple. Connect many neurons in layers and you get a neural network. Information flows forward, layer by layer.

INPUT — takes in the data HIDDEN — finds useful patterns inside OUTPUT — gives the answer
Every connection has a weight wᵢⱼ — what the network knows is stored in these numbers (plus the biases).
SEC 06 · LEARNING

Learning Rules

Learning simply means changing the weights. A learning rule is the recipe that decides how much to change each weight (Δw).

wnew=wold+Δw

Δw depends on the rule: supervised rules use the output error · Hebbian and competitive rules use neuron activity (no answer key)

HEBBIAN
Δwᵢ = η·xᵢ·y
"fire together, wire together" · unsupervised
PERCEPTRON
Δwᵢ = η·(t − y)·xᵢ
learn from mistakes · supervised
DELTA RULE
Δwᵢ = η·(t − y)·f′(net)·xᵢ
step downhill on the error · supervised · Widrow–Hoff (LMS) when f′ = 1
COMPETITIVE
Δw = η·(x − w), winner only
only the best-matching neuron learns · unsupervised
LEARNING RULE — the recipe that changes weights PARADIGM — the kind of feedback available ALGORITHM — the full step-by-step training procedure

SEC 08 · TRAINING

The Perceptron

Rosenblatt, 1958 — the first neuron that can learn. It makes a simple yes/no (+1 / −1) decision.

INPUTSx₁ … xₙ
WEIGHTED SUMΣwᵢxᵢ + b
STEP FUNCTIONfire or not
OUTPUTy ∈ { +1, −1 }

DECISION FUNCTION

y = +1 if Σwᵢxᵢ + b ≥ 0 · else −1

WHAT IT LEARNS — A DECISION BOUNDARY

it can only split data with a straight line → so we need multilayer networks
SEC 09 · TRAINING

A Tiny Learning Step

One example, one correction — small numbers so you can check it by hand.

01 · GIVEN
x = [1, 0, 1]
w = [0.2, −0.3, 0.1]
b = 0.1 · t = −1 · η = 0.1
02 · NET INPUT
net = 0.2·1 + (−0.3)·0
+ 0.1·1 + 0.1
= 0.4
03 · OUTPUT
net ≥ 0 →
y = +1
04 · ERROR
e = t − y
= −1 − (+1)
= −2 (wrong)
05 · UPDATE
Δwᵢ = η·e·xᵢ
Δw = [−0.2, 0, −0.2]
Δb = −0.2
wnew = [0.0, −0.3, −0.1] bnew = −0.1 re-check the same input: net = −0.2 → y = −1 = target ✓
Repeat this over all the examples and the weights settle on the right answer — as long as a straight line can separate the classes.

MLP — Scaling the Perceptron

A multilayer perceptron stacks neurons in layers. Hidden layers build up from simple features to complex ones.

INPUT — raw data HIDDEN 1 — simple features HIDDEN 2 — combined features OUTPUT — the decision
MLPthe ARCHITECTURE — what the network is: layers, weights, activations
VS
BACKPROPAGATIONthe TRAINING ALGORITHM — how it learns: error backward, weights updated
a hidden layer with non-linear activation can solve problems no straight line can (e.g. XOR) — a single perceptron can't

SEC 13 · TRAINING

Backpropagation — Step by Step

01Initialisesmall random weights & biases
02Forward passpass the inputs through each layer to get the output
03Compute errorhow wrong? E = ½ Σ (t − y)²
04Output δoutput blame: δₖ = (tₖ − yₖ)·f′(netₖ)
05Hidden δhidden blame: δⱼ = f′(netⱼ)·Σ δₖwⱼₖ
06Update weightsΔwᵢⱼ = η·δⱼ·xᵢ (= −η ∂E/∂wᵢⱼ)
07Repeatgo through all the examples (one epoch)
08Stopwhen the error is small enough (or max epochs)
each layer's blame (δ) is worked out from the layer above it · δ = −∂E/∂net
SEC 14 · MEMORY

When a Network Becomes a Memory

Hopfield, 1982 — a network that stores patterns as memories. Show it a messy version and it settles back to the closest stored one.

E = — SETTLING — ENERGY DECREASING
RECURRENTevery neuron is linked to every other neuron (not itself), and each link works both ways equally: wᵢⱼ = wⱼᵢ.
STORAGEpatterns are stored in the weights using Hebb's rule (neurons that fire together link up) — it can reliably store about 0.14·N patterns (N = number of neurons).
DYNAMICSneurons update one at a time, and the network's “energy” keeps dropping until it settles.
RETRIEVALthe settled states are the stored memories (a few false ones can appear too) — a noisy input rolls down into the nearest one.

SEC 18 · CLOSING

What We Learned

01

A neuron is just arithmetic — multiply inputs by weights, add them up, add a bias, then decide: y = f(Σwᵢxᵢ + b).

02

Learning means changing weights — experience gets stored as numbers.

03

The kind of feedback decides the learning type — supervised, unsupervised or reinforcement.

04

The perceptron learns from its mistakes; the delta rule makes the fix bigger when the mistake is bigger.

05

Backpropagation sends the error backward, so multilayer networks can learn.

06

A network can act as a memory — Hopfield networks recall whole patterns from partial clues.
