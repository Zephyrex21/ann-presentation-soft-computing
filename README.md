## Highlights

- **18 slides** covering the complete Unit IV syllabus, from the biological neuron to Hopfield memory
- **Interactive artificial neuron** — click the weights and bias and watch the output change
- **Animated backpropagation** — see the forward pass, the error flowing back, and the weight update
- **Hopfield memory demo** — a noisy pattern repairs itself, one cell at a time
- **Worked numerical example** of a perceptron learning step that you can check by hand
- **Zero dependencies** — a single `index.html` file that runs fully offline

## What's Covered

| Part | Slides | Topics |
|:--|:--:|:--|
| **1 · Foundations** | 1 – 5 | Biological neuron · McCulloch–Pitts model · artificial neuron · activation functions · network architecture |
| **2 · Learning** | 6 – 13 | Learning rules · supervised / unsupervised / reinforcement · perceptron · delta rule · MLP · backpropagation |
| **3 · Memory & Uses** | 14 – 18 | Hopfield network · associative memory · pattern recognition · forecasting · image processing · takeaways |

## Run It

**Online:** open the [live demo](https://zephyrex21.github.io/ann-unit4-presentation/).

**Locally:**

```bash
git clone https://github.com/Zephyrex21/ann-presentation-soft-computing.git
cd ann-unit4-presentation
# just open index.html in any modern browser
```

## Controls

| Key / Action | Result |
|:--|:--|
| `↑` `↓` `→` `Space` `PageDown` | Move between slides |
| `F` | Toggle fullscreen |
| **SECTIONS** button | Jump to any slide |
| Click a weight or the bias *(slide 4)* | Change it and see the output update |
| **VIEW TEAM** *(slide 1)* | Open the team list |
